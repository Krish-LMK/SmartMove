# SUMO simulation

SUMO (Simulation of Urban MObility, version 1.28.0 used here) simulates individual vehicles on a road network.
Networks come from OpenStreetMap through SUMO's `osmWebWizard`.

## Scenarios
| Folder | Area | Status |
|---|---|---|
| `ebene_reduit/` | About 2.7 km × 1.9 km around Ébène–Réduit (lon 57.479–57.515, lat −20.256 to −20.239) | Network and demand in place; one hour of random demand (230 bus, 308 motorcycle, 676 passenger, 136 truck trips; seeds 42–45) |
| `port_louis/` | Central Port Louis, about 2.1 km × 1.3 km (lon 57.489–57.511, lat −20.168 to −20.156) | Network and demand in place; one hour of random demand (165 bus, 205 motorcycle, 492 passenger, 99 truck trips; seeds 42–45); one baseline run completed |

## Files in each scenario folder
| File | Purpose |
|---|---|
| `osm.net.xml.gz` | road network (from OpenStreetMap) |
| `osm.*.trips.xml` | vehicle demand generated by `randomTrips.py` (**assumption**, not observed traffic) |
| `osm.sumocfg` | main configuration; run this |
| `output.add.xml`, `osm.view.xml` | extra output and view settings |
| `build.bat`, `run.bat` | commands used to generate the trips and open the GUI (Windows) |
| `osm_bbox.osm.xml.gz`, `osm.netccfg`, `osm.ogcfg` | OSM extract and the wizard's settings |

## Run it
Needs SUMO installed and `SUMO_HOME` set.
```bash
cd sumo/ebene_reduit
sumo -c osm.sumocfg          # no GUI, runs to the end of the demand
# or: sumo-gui -c osm.sumocfg   (press Play and let it finish)
```
Outputs are `tripinfos.xml`, `stats.xml` and `edgeData.xml`. They are git-ignored.
Check that `tripinfos.xml` contains many `<tripinfo` lines; an empty file means the run stopped too early.

## Before / after comparison
1. Copy the scenario folder to `baseline/` and `intervention/` inside it (or two sibling folders).
2. Change only the intervention (for example demand or road/bus settings) and keep the seeds the same.
3. Run both, then compare the two `tripinfos.xml` files (before first, after second):
```bash
python src/sumo_parse.py baseline/tripinfos.xml intervention/tripinfos.xml
```
4. Save the summary tables to `outputs/` and label them **SIMULATED**.

## Adding another scenario
Copy the wizard output into `sumo/<name>/` and leave out `tripinfos.xml`, `stats.xml` and `edgeData.xml`.
Check the files for personal paths first (`grep -r "Users" sumo/<name>`).

## Honesty note
Demand here is random and assumed. Simulated travel times show how scenarios compare under the same assumptions.
They are not measurements of real traffic.
